# qmd Docs Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `docs/` searchable by meaning in every Claude session, refreshed automatically whenever a doc is written, with no reminder needed.

**Architecture:** A local [qmd](https://github.com/tobi/qmd) index over `docs/` is reached three ways: a **project skill** tells the agent when and how to query it, a **shared hook script** reindexes on every write to `docs/` (and at session start, for out-of-band edits), and a **CLAUDE.md rewrite** makes querying the documented first move instead of the grep ladder. No MCP server, no source-code indexing.

**Tech Stack:** Bun (JS runtime), `@tobilu/qmd` (search engine, local GGUF models), bash + `flock` + `python3` (hook script), Claude Code hooks and skills.

## Global Constraints

- **Runtime floor:** qmd requires Node ≥22 or Bun ≥1.0. This machine has **neither inside WSL** — the only Node (v24.13.1) is a Windows mise install whose shims fail here (`exec: mise: not found`). Install Bun.
- **No `jq` on this machine.** `flock` (`/usr/bin/flock`), `bash` (`/usr/bin/bash`), and `python3` (3.12.3) are present. Hook scripts must parse JSON with `python3`, never `jq`.
- **Collection name is exactly `redstonespecs-docs`** everywhere — skill, CLAUDE.md, hook script.
- **Corpus is `docs/**/*.md` plus the root `CLAUDE.md`.** Never `src/`.
- **Hooks must never block a turn** — every hook entry sets `"async": true`.
- **Hooks must degrade silently** — no qmd installed means clean `exit 0`, never an error.
- **Commit style:** no `Co-Authored-By: Claude` trailer, no Claude attribution. Commit directly to `main`.

### Task 2: The reindex hook

**Files:**
- Create: `.claude/hooks/qmd-reindex.sh` (mode 755)
- Create: `.claude/settings.json`

**Interfaces:**
- Consumes: the `redstonespecs-docs` collection and working `qmd` binary from Task 1.
- Produces: `.claude/hooks/qmd-reindex.sh`, invoked with **no arguments** and the hook payload on **stdin**. Contract: exit 0 always; reindex only when stdin carries no `tool_input.file_path` (SessionStart) or carries one matching `<repo>/docs/**/*.md`. Appends to `.qmd/reindex.log`.

- [ ] **Step 1: Write the hook script**

Create `.claude/hooks/qmd-reindex.sh`:

```bash
#!/usr/bin/env bash
# Reindex the qmd docs collection.
#
# Wired to two events in .claude/settings.json:
#   PostToolUse(Write|Edit) — payload on stdin carries .tool_input.file_path
#   SessionStart            — payload carries no file path; catches out-of-band
#                             edits (git pull, rebase, IDE) the write hook can't see
#
# Always exits 0. A failure here must never interrupt a turn.
set -u

REPO="${CLAUDE_PROJECT_DIR:-$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)}"

# Not installed → no-op, so the repo stays usable without qmd.
command -v qmd >/dev/null 2>&1 || exit 0

# Read the payload if one is piped in. python3, not jq: jq is not installed here.
payload=""
if [ ! -t 0 ]; then
  payload="$(cat)"
fi

if [ -n "$payload" ]; then
  path="$(printf '%s' "$payload" | python3 -c '
import json, sys
try:
    d = json.load(sys.stdin)
except Exception:
    sys.exit(0)
ti = d.get("tool_input") or {}
print(ti.get("file_path") or "")
' 2>/dev/null)"

  # A path present but outside docs/*.md means this was a source edit — skip.
  # No path at all (SessionStart) falls through and reindexes.
  if [ -n "$path" ]; then
    case "$path" in
      "$REPO"/docs/*.md|docs/*.md) ;;
      *) exit 0 ;;
    esac
  fi
fi

mkdir -p "$REPO/.qmd"

# Serialize. Rapid successive doc writes would otherwise race on the SQLite DB.
# Non-blocking: a run that arrives while another holds the lock skips, because the
# in-flight run rescans by mtime and picks the newer file up anyway.
exec 9>"$REPO/.qmd/reindex.lock"
flock -n 9 || exit 0

cd "$REPO" || exit 0
{
  echo "=== $(date -Is) reindex (trigger path: ${path:-session-start}) ==="
  qmd update && qmd embed
} >>"$REPO/.qmd/reindex.log" 2>&1

exit 0
```

# Searching the docs

`docs/` is indexed by [qmd](https://github.com/tobi/qmd) as the collection **`redstonespecs-docs`**
(~100 articles). Query it before grepping — articles are hyperspecialized and often describe a
concept in different words than the question uses, which is exactly the case lexical search misses.

## Default query

```bash
qmd query "<the user's question, in natural language>" -c redstonespecs-docs -n 8 --format md
```

Then **`Read` the files it names.** qmd returns excerpts; the article is the source of truth and the
code is the source of truth above that. Cite `file:line` from the real file, never from an excerpt —
and per CLAUDE.md, verify a doc's own `file:line` citations against current code before relying on
them, since articles drift.

## Which mode

Measured on this corpus, this machine:

| Command | What it does | Time | Use for |
|---|---|---|---|
| `qmd search` | BM25 keyword | <search-time> | Exact identifiers: `SpecBlockEntity`, `DiodeBlock.FACING`, `ClientSpec` |
| `qmd vsearch` | Vector only | <vsearch-time> | Conceptual questions when the reranker isn't worth the wait |
| `qmd query --no-rerank` | Expansion, no rerank | <query-norerank-time> | Faster `query`; the usual escape hatch |
| `qmd query` | Expansion + rerank | <query-time> | Default for natural-language questions |

Rules of thumb:

- Searching for a **symbol you can spell exactly**? `qmd search` — BM25 beats embeddings at this and
  is far faster.
- Searching for a **concept**? `qmd query`.
- Add `--intent "<what a good answer looks like>"` to sharpen a vague question.
- `--format md` for reading, `--format files` when you only want paths to feed into `Read`.

## When qmd finds nothing

Degrade, don't dead-end — fall back to the ladder in CLAUDE.md:

1. Open the category `INDEX.md` under the most likely `docs/` folder.
2. `grep -ri "<keyword>" docs/`.
3. Only then conclude the doc doesn't exist — and consider writing it, per CLAUDE.md's
   "How to save learnings".

## Freshness

The index reindexes automatically on every write to `docs/`, so an article is searchable within
seconds of being written. **Do not run `qmd update` or `qmd embed` by hand** — redundant runs just
contend for the reindex lock.
```
